# About Apps

full-stack food ordering web application using React (Vite), Express.js, and MySQL. The application allows users to browse food and drink menus, add items to a shopping cart, manage their orders, and complete the checkout process by placing an order. The system provides a simple and intuitive ordering experience while demonstrating full CRUD operations and database integration.
